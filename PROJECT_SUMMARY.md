# v1.20 Everyday Explore More Revision

This iteration keeps the Core Path small while revising the entire Explore More curriculum to align with **everyday Eritrean/Asmara-style conversational Tigrinya**. The curriculum now treats grammar as explanation for real scenes: family identity, describing people, names, age, school, work, home visits, hospitality, phone/text check-ins, plans, requests, public places, care/comfort, respectful relationship language, reading-to-reply, and cultural interpretation with humility.

## Major v1.20 changes

- Explore More reordered around daily conversation before abstract grammar.
- Every Explore More phase retitled/reframed around a real conversational use case.
- Added conversation-bridge lessons across the abstract grammar phases.
- Added a conversation ladder and refreshed reading ladder.
- Kept Core Path unchanged so the beginner on-ramp stays focused.
- Expanded glossary, phonetic cues, and romanization coverage for new everyday conversation vocabulary.
- Maintained checkpoint blueprint validation, adaptive review, corpus-wide phonetic support, and no-audio honesty.

## Honest scope

The site can build fidel recognition, reading, pattern reasoning, controlled written production, self-correction, and text-based everyday communication. It still cannot fully teach pronunciation, listening, rhythm, or live spontaneous conversation without audio and fluent speaker interaction.

## Content status

All new everyday conversation material is marked as a pedagogical draft / review-needed. The content is source-informed, but naturalness, tone, politeness, register, and Eritrean/Asmara usage need fluent speaker review before classroom use.
